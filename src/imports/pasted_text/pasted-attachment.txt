Create a highly interactive, modern personal portfolio website for Ashen Randira, a software engineering undergraduate and full-stack developer.

Important: this must feel original and playful, not like a generic AI portfolio, dashboard, SaaS landing page, or a copy of any existing portfolio. Use a dark refined visual style, but do not make the whole page black. Use deep charcoal / ink backgrounds with subtle blue, violet, electric lime, and warm amber highlights. Keep it clean, premium, and slightly experimental.

Design direction:
- Full-screen desktop-first portfolio with responsive mobile layout.
- Strong typography with oversized editorial headings, but keep body text minimal.
- Use asymmetrical composition, overlapping elements, custom lines, subtle grain/noise, and visual depth.
- Avoid repetitive rounded cards, huge gradients, excessive glassmorphism, and generic icon rows.
- This is a developer portfolio, so it should feel technically capable but still personal and creative.

Main interaction idea:
Create a soft custom cursor made of a small glowing dot with a trailing ring of tiny dots. The cursor reacts differently when hovering over interactive elements:
- On buttons, it expands and shows labels like “OPEN”, “VIEW”, or “SCROLL”.
- On project previews, it becomes a draggable/hovering circle.
- Text links slightly shift and reveal a colored underline.
- Project images gently zoom, tilt, and reveal metadata on hover.
- Include smooth scrolling and subtle parallax layers, but keep motion elegant and not distracting.
- Respect reduced-motion preferences.

Page structure:

1. Hero / Opening screen
- A very minimal, striking opening view.
- Main text:
  “ASHEN
   RANDIRA”

  “Software engineering student building thoughtful digital experiences.”
- A short rotating line under it:
  “Full-stack developer / Problem solver / Curious builder”
- Include a small interactive “Enter the work →” control rather than a standard navbar-heavy layout.
- Add a visual abstract composition on the right or behind the text: layered glowing shapes, floating code fragments, grid lines, and a soft cursor-reactive field. Do not use stock photos.

2. Navigation
- Thin, minimal top navigation with:
  Work / About / Journey / Contact
- On hover, each item has a unique microinteraction, such as letters spacing apart or a tiny colored beam sliding beneath it.
- Add a small availability indicator: “Currently building & learning”.

6. Contact / ending screen
- Big ending text:
